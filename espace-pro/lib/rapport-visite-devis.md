# Rapport de visite de devis EF

## Objectif

Cette compétence sert à transformer une visite de chantier, des notes terrain, des photos ou un relevé oral en un rapport clair et structuré destiné à préparer un devis.

Le rapport doit permettre à une autre personne de comprendre rapidement :

- où se situe l'intervention ;
- ce qui a été observé ;
- quels végétaux ou zones sont concernés ;
- quelles contraintes existent ;
- quelles préconisations sont retenues ;
- quels moyens techniques sont probablement nécessaires ;
- comment les rémanents doivent être gérés ;
- quelles informations doivent encore être confirmées avant chiffrage ;
- quels points particuliers doivent être signalés à l'équipe de production.

Lorsque les compétences « Référentiel arboricole EF » et « Devis arboricole EF » sont disponibles, appliquer leur logique de raisonnement.

---

## Finalité du rapport

Le rapport de visite n'est pas un devis.

Il sert d'interface entre :
1. la visite terrain ;
2. l'analyse arboricole ;
3. le chiffrage ;
4. la rédaction du devis ;
5. la préparation du chantier.

Il doit donc être suffisamment précis pour éviter une seconde visite inutile lorsque les informations nécessaires ont déjà été recueillies.

---

## Règle fondamentale

Ne jamais inventer une donnée non observée ou non fournie.

Si une information est incertaine, utiliser des formulations comme :
- « à confirmer » ;
- « environ » ;
- « semble nécessiter » ;
- « sous réserve de vérification » ;
- « non vérifié lors de la visite ».

Toujours distinguer :
- observation ;
- hypothèse ;
- préconisation ;
- information client ;
- donnée à confirmer.

---

## Structure standard du rapport

### 1. Identification du chantier

Indiquer si les informations sont connues :

- nom du client ;
- adresse ou lieu d'intervention ;
- commune ;
- date de visite ;
- personne rencontrée ;
- objet de la demande ;
- origine de la demande si utile.

Ne pas inventer les éléments absents.

---

### 2. Contexte général

Résumer en quelques lignes :

- nature du site ;
- contraintes principales ;
- demande du client ;
- état général apparent ;
- raison de la visite.

Exemples :
- branches en contact avec une toiture ;
- arbre présentant une casse récente ;
- entretien global d'une propriété ;
- suppression d'une haie ;
- débroussaillage de parcelles ;
- sécurisation d'un arbre ;
- entretien d'un parc arboré.

---

### 3. Observations arboricoles

Pour chaque arbre ou groupe d'arbres concerné, relever si possible :

- essence ;
- nombre approximatif ;
- stade de développement ;
- état physiologique apparent ;
- architecture ;
- historique de taille visible ;
- présence de bois mort ;
- branches cassées ;
- défauts d'insertion ;
- écorces incluses ;
- cavités ;
- champignons visibles ;
- dépérissement ;
- contraintes racinaires ou de sol ;
- proximité de bâtiments, réseaux, voirie ou équipements.

Ne pas transformer une observation visuelle en diagnostic certain lorsque les éléments sont insuffisants.

---

### 4. Demande du client

Noter la demande telle qu'elle est formulée.

Exemple :
« Le client souhaite réduire fortement l'arbre afin de dégager la toiture. »

Puis, si nécessaire, distinguer cette demande de la préconisation retenue :

« Au regard de l'architecture observée, une réduction généralisée n'est pas préconisée. Un dégagement ciblé des branches en contact avec la toiture est préférable. »

Cette distinction est importante pour conserver la logique de décision.

---

### 5. Préconisation retenue

Décrire précisément l'intervention recommandée.

Utiliser une terminologie adaptée :

- taille sanitaire ;
- taille d'adaptation ;
- relevé de couronne ;
- dégagement ciblé ;
- réduction localisée ;
- réduction raisonnée ;
- suppression de bois mort ;
- reprise de casses ;
- haubanage ;
- démontage ;
- abattage ;
- rognage ;
- débroussaillage ;
- entretien d'arbustes ;
- broyage ;
- évacuation.

Lorsque plusieurs options sont possibles, les hiérarchiser.

---

### 6. Justification technique

Ajouter une justification courte lorsque celle-ci est utile.

Exemples :
- limiter les contraintes sur une insertion fragilisée ;
- conserver le volume général de la couronne ;
- éviter une réduction excessive ;
- supprimer uniquement les branches en contact avec l'ouvrage ;
- accompagner une architecture issue d'un ancien étêtage ;
- sécuriser une zone de passage ;
- conserver les arbres périphériques ;
- faciliter l'accès ou l'entretien futur.

Le rapport doit aider à comprendre pourquoi la solution retenue est cohérente.

---

### 7. Moyens techniques envisagés

Relever si connu :

- grimpe ;
- nacelle ;
- démontage avec rétention ;
- broyeur ;
- rogneuse ;
- robot débroussailleur ;
- mini-chargeur ;
- besoin de balisage ;
- besoin d'alternat de circulation ;
- besoin d'autorisation ou d'arrêté ;
- difficulté d'accès ;
- portage manuel ;
- accès engins ;
- pente ;
- sol fragile.

Ne pas considérer ces moyens comme définitifs si la visite ne permet pas de les confirmer.

---

### 8. Contraintes de chantier

Noter toute contrainte utile au chiffrage ou à la production :

- circulation ;
- stationnement ;
- riverains ;
- lignes électriques ;
- bâtiments ;
- clôtures ;
- portails ;
- accès étroits ;
- terrain pentu ;
- sol humide ;
- piscine ;
- réseaux enterrés ;
- voisinage ;
- horaires ;
- zone publique ;
- école ;
- résidence ;
- nécessité de protéger certains ouvrages.

---

### 9. Gestion des rémanents

Préciser ce qui est souhaité ou prévu :

- broyage sur place ;
- copeaux laissés sur site ;
- copeaux répartis au pied des arbres ;
- bois laissé au client ;
- bois évacué ;
- rémanents évacués en déchetterie ;
- broyage sans évacuation ;
- aucune valorisation prévue ;
- traitement spécifique pour certaines essences.

Ne pas supposer l'évacuation si elle n'a pas été décidée.

---

### 10. Rognage et finitions

Indiquer si les souches doivent être :

- laissées en place ;
- coupées au ras du sol ;
- rognées ;
- retirées par un autre moyen.

Indiquer les finitions réellement prévues :

- nettoyage de la zone ;
- passage du robot débroussailleur ;
- broyage complémentaire ;
- régalage du broyat ;
- aucune remise en état lourde.

Ne pas promettre une remise en état générale du terrain si elle n'est pas prévue contractuellement.

---

### 11. Éléments nécessaires au chiffrage

Le rapport doit permettre d'identifier :

- nombre de jours estimé si connu ;
- nombre d'hommes envisagé si connu ;
- matériel majeur nécessaire ;
- volume de broyage approximatif ;
- évacuation nécessaire ou non ;
- quantité de bois ;
- difficulté d'accès ;
- nécessité d'une nacelle ;
- nécessité d'une rétention ;
- surface approximative ;
- métrés linéaires ;
- nombre de souches ;
- prestations complémentaires éventuelles.

Ne jamais inventer un temps ou un prix.

---

### 12. Points à confirmer

Créer cette rubrique lorsqu'une information manque.

Exemples :
- métrage exact ;
- présence d'un réseau enterré ;
- autorisation de stationnement ;
- accord du voisin ;
- capacité d'accès de la nacelle ;
- besoin réel de haubanage ;
- destination du bois ;
- possibilité de laisser les copeaux sur place.

Cette section doit éviter que les incertitudes soient oubliées au moment du devis.

---

### 13. Photos

Lorsque des photos sont disponibles, le rapport peut s'y référer.

Exemples :
- « Voir photo 1 : branche en contact avec toiture. »
- « Voir photo 3 : insertion présentant une écorce incluse. »
- « Voir vues aériennes pour le linéaire approximatif de haie. »

Ne pas prétendre observer sur une photo ce qui n'est pas clairement visible.

---

## Version courte

Pour une visite simple, produire une fiche concise :

**Contexte :**  
...

**Travaux préconisés :**
- ...
- ...

**Contraintes :**
- ...

**Rémanents :**
- ...

**À confirmer :**
- ...

---

## Utilisation par un conducteur de travaux

Le rapport doit être exploitable par un conducteur de travaux ou une assistante de direction pour préparer le devis sans devoir réinterpréter les notes.

Privilégier donc :

- des phrases factuelles ;
- des unités précises ;
- des termes techniques homogènes ;
- des informations séparées par thème ;
- des réserves explicites ;
- un niveau de détail suffisant pour le chiffrage.

Éviter les formulations trop orales ou ambiguës.

---

## Transmission vers le devis

Lorsqu'un rapport de visite est ensuite transformé en devis :

1. reprendre uniquement les éléments confirmés ;
2. supprimer les notes internes inutiles au client ;
3. conserver la justification technique utile ;
4. retirer les hypothèses non vérifiées ;
5. simplifier la formulation ;
6. conserver les limites de prestation ;
7. reprendre fidèlement la gestion des rémanents ;
8. ne pas transférer dans le devis les commentaires internes de production.

---

## Cas d'un arbre présentant un défaut

Le rapport doit distinguer :

**Observation :**
« Présence de deux écorces incluses au niveau de la cépée. »

**Conséquence potentielle :**
« Ces insertions peuvent constituer des zones de faiblesse mécanique. »

**Préconisation :**
« Fourniture et pose d'un hauban dynamique afin de limiter l'amplitude de mouvement entre les axes concernés. »

Ne pas écrire directement :
« arbre dangereux ».

---

## Cas d'un dégagement de bâtiment

Exemple de logique attendue :

**Observation :**
Des branches sont en contact avec la façade et la toiture.

**Préconisation :**
Réaliser une taille d'adaptation ciblée afin de créer une distance fonctionnelle entre les premiers axes et les ouvrages.

**Principe :**
Conserver le volume général des couronnes lorsqu'elles se développent au-dessus des bâtiments.

---

## Cas d'un ancien étêtage

Le rapport doit relever :

- présence d'anciennes coupes ;
- développement d'axes secondaires ou suppléants ;
- éventuelles ruptures ;
- défauts d'insertion ;
- charge mécanique.

Puis formuler une préconisation adaptée.

---

## Cas d'un débroussaillage

Le rapport doit préciser :

- surface approximative ;
- nature de la végétation ;
- éléments à conserver ;
- arbres à supprimer ;
- accès ;
- pente ;
- possibilité de broyage ;
- destination des produits ;
- besoin de robot, broyeur ou autre matériel.

---

## Cas d'une haie à supprimer

Relever si possible :

- essence ;
- linéaire approximatif ;
- nombre de retours ;
- haies intérieures ;
- sujets isolés ;
- hauteur approximative ;
- diamètre moyen ;
- accès ;
- présence de clôtures ;
- rognage des souches ;
- évacuation ;
- nettoyage final prévu.

---

## Priorité et urgence

Si utile, indiquer :

- urgent ;
- prioritaire ;
- à programmer ;
- entretien courant ;
- à surveiller ;
- à recontrôler.

Ne pas qualifier une intervention d'urgente sans élément objectif.

---

## Contrôle qualité avant validation

Avant de finaliser le rapport, vérifier :

- que le client et le lieu sont correctement identifiés ;
- que les essences sont correctes ;
- que les observations sont séparées des hypothèses ;
- que les préconisations sont cohérentes avec le référentiel arboricole ;
- que les contraintes d'accès sont mentionnées ;
- que la gestion des rémanents est claire ;
- que les besoins de matériel sont identifiés ;
- que les points à confirmer sont listés ;
- qu'aucun prix n'a été inventé ;
- que le rapport permet réellement de préparer le devis.

---

## Comportement attendu

Lorsque l'utilisateur fournit des notes vocales, du texte brut ou des photos :

1. extraire les informations utiles ;
2. les classer dans les rubriques pertinentes ;
3. corriger les termes arboricoles si nécessaire ;
4. conserver les incertitudes ;
5. ne pas créer de fausse précision ;
6. produire un rapport immédiatement exploitable ;
7. si une donnée indispensable au devis manque, la faire apparaître dans « Points à confirmer » plutôt que bloquer inutilement la rédaction.
